# 合成万物 · Algebra Drop

一个从 Field 合成到 Set 的代数版“合成大西瓜”。相同球相碰会合成更大一级的结构，持续越过警戒线两秒则结束。

**[点击直接游玩](https://zhuozheng2006.github.io/algebra-drop/)**

## 操作

- 电脑：鼠标移动瞄准，点击投球；也支持方向键和空格。
- 手机：拖动瞄准，松手投球。
- 支持暂停、音效、连击计分和本机最高分保存。

## 合成顺序

Field → ED → PID → UFD → GCD Domain → ICD → Integral domain → Commutative Ring → Ring → Rng → Ab → Grp → Mon → Sg → Set

Rng 的中文名为伪环，不要求乘法单位元；ICD 指整闭整环。路线表示逐步放宽性质或遗忘运算，并非集合基数排序。Rng → Ab 忘掉乘法，Sg → Set 忘掉运算。两个 Set 合成消去，奖励 2000 基础分。

## 本地运行

下载 `index.html` 并用浏览器打开即可。纯 HTML/CSS/JavaScript，无需安装依赖或后端。
